आपके documents

🌐 इंटरनेट से खोज — पूरी तरह मुफ़्त

स्रोत: Wikipedia, DuckDuckGo (और आपका अपना SearXNG, अगर लगाया हो) — कोई API key या पैसा नहीं लगता। Google और ChatGPT की कोई मुफ़्त official API नहीं है, इसलिए उन्हें सीधे नहीं बुलाया जाता; जवाब न मिलने पर "Google / ChatGPT में खोलें" बटन ब्राउज़र में खुलते हैं। ध्यान रहे: सिर्फ़ आपका सवाल इंटरनेट पर जाता है, आपके documents या याददाश्त नहीं। जिस जवाब पर 👍 देंगे, वह याद हो जाता है और अगली बार बिना इंटरनेट के मिलता है।

🧠 Piyu की याददाश्त और सीख

सब कुछ सिर्फ़ आपके device/server पर रहता है। यह मशीन-लर्निंग नहीं, आपकी बातचीत से सीखे गए सादे आँकड़े और याद हैं — जो आप देख, बदल और मिटा सकते हैं।

🎙 Piyu की आवाज़ — चुनें

आवाज़ (browser की आवाज़ — backup)

Alarm

P1 (अत्यावश्यक) alarm शांत समय में भी पूरी आवाज़ में बजता है, जब तक "पूरी तरह चुप" न चुना हो।

बंद है।

कहिए: "हे पीयू, अभी क्या करना है?" या सिर्फ़ "हे पीयू" — फिर वह "जी सर?" बोलेगी। Guide खुला हो या alarm बज रहा हो तो wake word के बिना भी "हो गया / दोबारा / पीछे / 5 मिनट बाद / रोको" चलता है। बोलते समय उसे रोकने के लिए "हे पीयू, रोको" कहें।

Alarm तब बजता है जब Piyu का tab/app खुला हो। फ़ोन बंद होने पर भी बजाने के लिए 📅 Calendar बटन से alarm phone के calendar में डालें।

Data, Backup और Sync

⚪ अभी sync नहीं हुआ

Logout तक Piyu पीछे (background) में चलती रहेगी

Data इस device के IndexedDB में और आपके अपने Piyu server (data/ फ़ोल्डर) में रहता है — कोई cloud या paid API नहीं। दूसरे device से sync के लिए computer पर ./run.sh --lan चलाएँ और फ़ोन से वही address खोलें; console में दिखा token यहाँ डालें।
